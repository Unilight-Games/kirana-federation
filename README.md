# สหพันธรัฐแห่งคีรันนา: ชุดไฟล์สำหรับ GitHub Pages

เกมกระดานการเมืองและเศรษฐกิจแห่งคีรันนา เล่นกับ AI เรียนกติกาในโหมดสอนเล่น หรือชวนเพื่อนเล่นออนไลน์ ทั้งหมดอยู่ในหน้าเว็บนิ่งหน้าเดียว ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

กติกาค่าเริ่มต้นคือฉบับ 0.4.7: เกม 12 รอบ ยุคละ 3 รอบ ทุกรัฐวางแรงงานและจ้างแรงงานพร้อมกัน แรงงานยืนอยู่ที่เดิมข้ามรอบ สิ่งปลูกสร้างทำงานเองเมื่อโครงการของมันมีแรงงานเต็ม การปฏิรูปเปิดดูกองทหารกับกองพักแล้วทิ้งได้ 1 ใบ จากนั้นสับกองพักกับการ์ดใหม่รวมเข้ากองทหาร การ์ดทหารที่ได้มาใหม่ทุกทางเข้ากองทหารทันที บุกเบิกชนะได้สินค้าเท่าผลผลิตของการ์ดและสิทธิ์ผนวกดินแดนด้วยต้นทุนลด 2 เหมือนเดิม โจมตีชนะปล้นครึ่งหนึ่งของสินค้าที่ค้างบนโครงการเป้าหมาย ปัดขึ้น ภาระผู้นำหักเฉพาะการนับคะแนนที่สามอันดับแรกมีรัฐเสมอกัน จุดเปลี่ยนกระแส 5 เมื่อเล่น 4 รัฐ และแผงทุกรัฐมีตัวนับสัญลักษณ์อุดมการณ์ห้าสี ฉบับ 0.4.4 ใช้ตารางการ์ดทหารของผู้ออกแบบ กองเสื้อคลุมน้ำเงินอ่อนลง เพลงชาติให้ความชอบธรรม 2 ชาตินิยมให้ 1 เมื่อชนะบุกเบิก รัฐบาลทหารให้ 1 เมื่อชนะการโจมตีรัฐอื่น และการทูตเลือกได้ว่าจะสับกองพักทหารกลับเข้ากองทหารหรือเก็บไว้ ฉบับ 0.4.7 (12 พ.ย. 2026) ให้กระแสที่ถูกขยับจนถึงจุดเปลี่ยนพลิกระบอบทันทีในเทิร์นนั้นโดยไม่ต้องรอสภา ระบอบใหม่นับคะแนนทันทีหนึ่งครั้ง และถ้าพลิกระหว่างขั้นบริหาร สภาท้ายรอบนับอีกครั้ง การ์ดระบอบสองใบใช้ข้อความจากชีตของผู้ออกแบบ มานาเสรีลดเกณฑ์การค้ามูลค่าสูง 1 เกรฟแทนการเพิ่มราคาขายให้ตลาดกลาง รัฐบาลทหารจัดอันดับด้วยแท็กศาสตรา และเมื่อเล่น 3 รัฐ อันดับ 2 ของยุค IV ได้ 3 แต้ม ฉบับ 0.4.6 ให้การสร้างโครงการที่มีสัญลักษณ์อุดมการณ์ดันกระแสของสายนั้น 1 ช่องต่อสัญลักษณ์ เหมือนการ์ดวัฒนธรรมตอนวาง โครงการที่ได้จากการผนวกดินแดนไม่ดัน หน้าสร้างโครงการบอกว่าใบไหนดันกระแสสายใดและกระแสนั้นอยู่ที่ช่องไหน การ์ดทุกใบเท่าฉบับ 0.4.5 ซึ่งใช้ตารางการ์ดทหาร v3 ของผู้ออกแบบครบทุกใบ พลธนูยาวพลัง 3 ทหารผ่านศึกจักรวรรดิเก่าไม่มีอำนาจยิงเหนือกว่าแล้ว ค่ายฝึกทหาร ประเพณีนักรบ หลักนิยมการรบแยกเดี่ยวฆ่าหมู่ และเครื่องยนต์มานาแรมเจ็ทเพิ่มคำสำคัญให้การ์ดทีละใบ กองทัพมหาชนจ่ายอาหาร 3 เพิ่มโถมกำลังได้การรบละครั้ง วอกโซโฟนทอดสัญญาณกับเลนส์ขยายอาคมทิ้งการ์ดที่ดูลงกองพักได้ และประชาธิปไตยสังคมให้ความชอบธรรม 1 กับรัฐที่ป้องกันรัฐประหารได้ เกมที่บันทึกไว้จากฉบับก่อนยังเล่นต่อด้วยกติกาเดิมของมัน ตั้งแต่ 11 พ.ย. 2026 ผู้เล่นเลือกโหมดทดลอง **รัฐที่แตกแยก (Asymmetric)** ได้ตอนตั้งโต๊ะหรือตอนสร้างห้องออนไลน์ ทุกรัฐได้การ์ดผู้สนับสนุนที่ให้ความสามารถเฉพาะตัว ตั้งแต่ 11 พ.ย. 2026 ผู้เล่นเลือกเองว่าจะจ่ายสินค้าจากคลังหรือจากโครงการก่อน ที่ช่อง **จ่ายจาก** บนแผงรัฐ และหน้าค้าขายเลือกได้ทีละที่ว่าจะขายให้ตลาดกลางจากคลังหรือโครงการไหน ตั้งแต่ 13 พ.ย. 2026 เกมบอกเหตุผลทุกครั้งที่ข้ามคำถามที่ผู้เล่นรออยู่ ชนะบุกเบิกแล้วจ่ายต้นทุนผนวกไม่ไหว หรือสภาไม่ถามจ้างแรงงานเพราะอาหารไม่พอ ผู้เล่นคนนั้นเห็นกล่องเตือนว่าต้นทุนเท่าไร มีเท่าไร และขาดอะไร กล่องนี้ขึ้นแม้ปิดเอฟเฟกต์บนโต๊ะ ลอยเหนือป๊อปอัปที่เปิดตามมา และกดปิดได้ บันทึกเกมจดเหตุผลเดียวกันของทุกรัฐ รวมรัฐที่แรงงานครบ 10 คนซึ่งบอกครั้งเดียว การ์ดระบอบกลางโต๊ะมีแถว **ผู้เลือกระบอบยุคหน้า** บอกว่าถ้าเปลี่ยนยุคตอนนี้รัฐใดได้เลือก ชี้ที่แถวนี้เห็นจำนวนสัญลักษณ์ฐานอำนาจของทุกรัฐ กติกาตัดสินเมื่อเสมอ และระบอบที่เลือกได้ ชี้ที่แถบยุคบนรางรอบเห็นค่าประจำยุคกับการ์ดระบอบทั้งห้าใบที่ครองในยุคนั้นได้ พร้อมมาตรวัด นโยบาย และฐานอำนาจ บรรทัดผู้เลือกระบอบในบันทึกเกมบอกด้วยว่ากติกาข้อไหนตัดสิน และป๊อปอัปเลือกระบอบบอกผู้เลือกว่าทำไมได้เลือก

หน้าตาเกมเป็นเมืองยุคปฏิวัติอุตสาหกรรมแบบกอธิค: แผ่นเหล็กหล่อตอกหมุดทองเหลือง แสงตะเกียงแก๊ส กระจกสีประจำยุค การ์ดกระดาษเก่า เฟืองทองเหลืองนับรอบ และระฆังโบสถ์ตีบอกยุคใหม่ ฟอนต์ Taviraj, IBM Plex Sans Thai และ UnifrakturMaguntia โหลดจาก Google Fonts ถ้าโหลดไม่ได้ เกมใช้ฟอนต์ไทยของเครื่องแทน ตั้งแต่ 11 พ.ย. 2026 การรบเล่นสกิลของการ์ดทหารให้เห็นบนการ์ด อำนาจยิงเหนือกว่ายิงปืนใหญ่จากการ์ดของมัน กระสุนระเบิดลงบนการ์ดที่ถูกทำลายแล้วการ์ดนั้นลงกองพัก สกัดพุ่งข้ามไปชนการ์ดเป้าหมายจนขอบการ์ดสองใบซ้อนกัน การ์ดที่โดนชนกระเด็นถอย แล้วพลังของมันจึงลด ทะลวงพุ่งเข้าชนการ์ดใบล่าสุดของอีกฝ่ายโดยเลขของการ์ดนั้นไม่ลด ตั้งรับยกโล่เรืองแสงขึ้นจากการ์ด ส่วนนำทัพ สนับสนุน ทะลวง โถมกำลัง เสริมทัพ สอดแนม และเชื้อเพลิงมีเอฟเฟกต์ของตัวเอง ตัวเลขทุกตัวมาจากผลการรบของเอนจิน ปุ่ม **เปิดทั้งหมด** ข้ามเอฟเฟกต์ และปิดเอฟเฟกต์ได้ที่ช่อง **เอฟเฟกต์บนโต๊ะ** ในหน้าตั้งค่า

## ตั้งค่าครั้งแรก

1. สร้าง repository ใหม่บน GitHub แบบ **Public** ตั้งชื่ออะไรก็ได้ เช่น `federation`
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นคลัง (ลากวางทั้งโฟลเดอร์ผ่านหน้าเว็บได้) จากนั้นสร้างไฟล์ workflow บน GitHub: กด **Add file > Create new file** พิมพ์ชื่อ `.github/workflows/records.yml` แล้ววางเนื้อหาจากไฟล์ `workflow/records.yml` ในโฟลเดอร์นี้ลงไป กด Commit (GitHub รัน workflow จากตำแหน่ง `.github/workflows` เท่านั้น ส่วนสำเนาในโฟลเดอร์ `workflow` ลบทิ้งได้หลังสร้างเสร็จ)
3. ไปที่ **Settings > Pages** ช่อง Source เลือก **Deploy from a branch** เลือก `main` กับ `/ (root)` แล้วกด Save
4. ไปที่ **Settings > Actions > General** หัวข้อ Workflow permissions เลือก **Read and write permissions** แล้วกด Save ระบบบันทึกต้องเขียนไฟล์ในโฟลเดอร์ `data`
5. รอหนึ่งถึงสองนาที เกมจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อคลัง/`

## ลงชื่อเข้าใช้ Google (ต้องมีจึงบันทึกเกมได้)

ผู้เล่นต้องลงชื่อเข้าใช้ Google ก่อน เกมจึงบันทึกให้เล่นต่อได้ และชัยชนะจึงเข้าหอเกียรติยศ ยังไม่ลงชื่อก็เล่นได้ทุกโหมด แต่ปิดหน้าแล้วเกมหาย ตั้งค่าครั้งเดียวดังนี้

1. เปิดหน้า **Clients** ของ Google Cloud Console (`console.developers.google.com/auth/clients` อยู่ในหมวด **Google Auth Platform**) สร้างโปรเจกต์ใหม่หรือเลือกโปรเจกต์ที่มี
2. หน้า **Branding** กรอกชื่อแอปกับอีเมลติดต่อ หัวข้อ **App domain** ช่อง **Application home page** ใส่ที่อยู่หน้าเกม (`https://ชื่อผู้ใช้.github.io/ชื่อคลัง/`) ช่อง **Application privacy policy link** ใส่ที่อยู่เดียวกันตามด้วย `privacy.html` แล้วกด Save (Google ไม่ยอมให้กด Publish app จนกว่าจะมีสองช่องนี้) หน้า **Audience** เลือกผู้ใช้แบบ **External** แล้วกด **Publish app** (ถ้าค้างไว้ที่ Testing จะลงชื่อได้เฉพาะบัญชีที่เพิ่มเป็น test user) เกมใช้แค่ขอบเขตพื้นฐาน email, profile, openid ไม่ต้องเพิ่มขอบเขตอื่น
3. กลับหน้า **Clients** กด **Create client** เลือกชนิด **Web application** ช่อง **Authorized JavaScript origins** ใส่ `https://ชื่อผู้ใช้.github.io` (มีแค่ https กับชื่อโดเมน ไม่มีชื่อคลังหรือ / ต่อท้าย) แล้วกด Create
4. คัดลอก Client ID (ลงท้ายด้วย `.apps.googleusercontent.com`) เปิดไฟล์ `config.js` บน GitHub กดรูปดินสอ ใส่ไว้ในเครื่องหมายคำพูด แล้ว Commit:
   ```js
   googleClient: 'ใส่ Client ID ตรงนี้',
   ```
   Client ID ไม่ใช่ความลับ ใส่ในคลังสาธารณะได้

สิ่งที่เกมเก็บ: แฮชของรหัสบัญชี Google กับชื่อต้น ไว้ในเบราว์เซอร์ของผู้เล่นเอง และไม่ส่งให้ผู้เล่นคนอื่น ถ้าตั้งหอเกียรติยศอัตโนมัติไว้ ตอนลงชื่อเข้าใช้หน้าเกมส่งโทเค็นการลงชื่อไปให้สคริปต์ของเจ้าของเกมหนึ่งครั้ง สคริปต์ตรวจกับ Google แล้วเก็บแค่แฮชของรหัสบัญชี ไม่เก็บอีเมล การลงชื่อเข้าใช้ใช้ได้เฉพาะหน้าเว็บที่ต้นทางตรงกับที่ลงทะเบียนไว้ ไฟล์ที่เปิดจากเครื่อง (`file://`) จึงลงชื่อไม่ได้

**เครื่องผู้พัฒนา** บันทึกเกมได้โดยไม่ต้องลงชื่อเข้าใช้ ปลดล็อกครั้งเดียวต่อเบราว์เซอร์ที่ **ตั้งค่า > รหัสผู้พัฒนา** ในหน้าเกมเก็บไว้แค่แฮชซ้อนสองชั้นของรหัส อ่านซอร์สแล้วก็ไม่ได้รหัส ใช้ได้ทั้งหน้าเว็บ ไฟล์ในเครื่อง และหน้าอาร์ติแฟกต์ ถ้าทำรหัสหาย ขอรหัสใหม่แล้วแก้ค่า `DEV_HASH` ใน `index.html`

**หลังบ้านของผู้พัฒนา** ตัวเลือกชุดกฎ (ฉบับ 0.4.7 ค่าเริ่มต้น โหมดทดลองรัฐที่แตกแยกที่ทุกรัฐจั่วการ์ดผู้สนับสนุน 5 ใบเลือก 1 ฉบับ 0.4.6 กับโหมดรัฐที่แตกแยกของฉบับ 0.4.6 ฉบับ 0.4.5 กับโหมดรัฐที่แตกแยกของฉบับ 0.4.5 ฉบับ 0.4.4 กับโหมดรัฐที่แตกแยกของฉบับ 0.4.4 ฉบับ 0.4.3 ฉบับ 0.4.2 ที่ภาระผู้นำหักทุกการนับ ฉบับ 0.4.1 ฉบับ 0.4 ที่ปฏิรูปทิ้งได้เฉพาะกองพัก ฉบับ 0.4 ปฏิรูปตรวจพล ฉบับ 0.3 ตัวแปรจุดเปลี่ยน 5 ของฉบับ 0.3 และฉบับ 0.2) ห้องผู้ออกแบบที่จำลอง AI หลายเกม หัวข้อข้อที่หน้าเกมตีความกฎเอง รายการความต่างของฉบับ 0.3 และบรรทัดชุดกฎกับซีดในหน้าตั้งค่าระหว่างเกม ขึ้นเฉพาะแท็บที่เข้าระบบผู้พัฒนา ผู้เล่นทั่วไปเลือกได้สองโหมด คือปกติ (ฉบับ 0.4.7) และรัฐที่แตกแยก (Asymmetric) ที่เปิดให้ทุกคนตั้งแต่ 11 พ.ย. 2026 โต๊ะที่เคยตั้งไว้กับโหมดของฉบับ 0.4.4 ถึง 0.4.6 เปิดโหมดเดียวกันของฉบับ 0.4.7 ให้เอง

**เข้าสู่ระบบและออกจากระบบแยกต่อแท็บ** ทุกบัญชีมีโปรไฟล์ผู้นำ เกมที่บันทึก และตั๋วหอเกียรติยศของตัวเอง (เก็บใต้ `u.รหัสบัญชี` ในเบราว์เซอร์) แท็บใหม่เริ่มด้วยบัญชีที่ลงชื่อล่าสุดในเบราว์เซอร์นั้น ปุ่ม **ออกจากระบบ** มีทั้งบัญชี Google และบัญชีผู้พัฒนา กดแล้วมีผลเฉพาะแท็บนั้น แท็บอื่นเล่นต่อตามเดิม เครื่องที่ปลดล็อกแล้วมีปุ่ม **เข้าระบบผู้พัฒนา** ให้กดกลับเข้าได้ทันที บัญชีแรกที่ลงชื่อในเบราว์เซอร์หนึ่งรับโปรไฟล์เดิมของเบราว์เซอร์นั้นไป บัญชีถัดไปเริ่มตั้งผู้นำใหม่ของตัวเอง ผู้เยี่ยมชมใช้โปรไฟล์ร่วมของเบราว์เซอร์ แต่ได้ตัวตนออนไลน์ใหม่ทุกแท็บ สองแท็บที่ไม่ได้ลงชื่อบัญชีเดียวกันจึงเป็นผู้เล่นคนละคนเสมอ

ข้อจำกัด: ทุกการตรวจทำในเบราว์เซอร์ของผู้เล่น จึงเป็นกติกาบ้านที่คนแก้ไฟล์หน้าเว็บเองข้ามได้ ถ้าต้องการบังคับจริงต้องมีเซิร์ฟเวอร์ที่ตรวจโทเค็นของ Google

## หอเกียรติยศอัตโนมัติ ลานความคิดเห็น และสถิติการเล่น (Google Sheet + Apps Script)

ตั้งครั้งเดียว แล้วผู้ชนะที่ลงชื่อเข้าใช้จะขึ้นหอเกียรติยศเองตอนจบเกม ความคิดเห็นที่กดส่งขึ้นลานทันที เครื่องผู้พัฒนาลบรายชื่อหรือความคิดเห็นจากหน้าเกมได้ และสคริปต์เริ่มเก็บสถิติการเล่นให้ผู้พัฒนาดู ไม่ต้องเปิด GitHub ทุกคนที่เปิดหน้าหอเกียรติยศเห็นทันที

1. สร้าง Google Sheet ใหม่ใน Google Drive ตั้งชื่ออะไรก็ได้ เช่น `หอเกียรติยศ สหพันธรัฐ`
2. ในชีต กด **Extensions > Apps Script** ลบโค้ดตัวอย่าง แล้ววางเนื้อหาทั้งหมดจาก `scripts/hof-apps-script.gs` ใส่ Client ID ตัวเดียวกับใน `config.js` ที่บรรทัด `GOOGLE_CLIENT_ID` แล้วกดบันทึก (รูปแผ่นดิสก์)
3. กด **Deploy > New deployment** เลือกชนิด **Web app** ช่อง Execute as เลือก **Me** ช่อง Who has access เลือก **Anyone** แล้วกด Deploy
4. Google ขอสิทธิ์ให้สคริปต์ (อ่านเขียนชีตนี้ และเรียก Google เพื่อตรวจการลงชื่อ) ถ้าขึ้นว่า Google hasn't verified this app ให้กด **Advanced > Go to … (unsafe)** เพราะเป็นสคริปต์ของคุณเอง แล้วกด Allow
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) ไปใส่ใน `config.js` ที่ `hofEndpoint` แล้ว Commit ลองเปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"app":"kirana-federation-hof",...}`

การดูแล: บันทึกของเดือนที่กำลังเดินอยู่ในชีตชื่อ `hof` เดือนก่อน ๆ อยู่ในชีต `hof-archive` ความคิดเห็นอยู่ในชีต `cmt` รายการที่ผู้พัฒนาลบอยู่ในชีต `removed` จำนวนคนเข้าต่อวันอยู่ในชีต `daily` เกมที่เล่นอยู่ในชีต `games` บันทึกการเดินที่มากับผลในหอเกียรติยศอยู่ในชีต `hof-logs` บัญชีที่ถูกระงับอยู่ในชีต `blocked` และผลที่การตรวจทุกคืนนำออกอยู่ในชีต `hof-flagged` (สคริปต์สร้างชีตเองเมื่อใช้ครั้งแรก) ลบแถวในชีต `hof` หรือ `cmt` เพื่อเอาออกได้ทันทีเหมือนเดิม บัญชีหนึ่งส่งได้ไม่เกิน 20 บันทึกและ 30 ความคิดเห็นต่อวัน สคริปต์สร้างทุกช่องใหม่เอง ตรวจว่าคะแนนสุทธิเท่าความชอบธรรมลบตราบาป และผู้ชนะไม่ต่ำกว่าคู่แข่ง เวลาของความคิดเห็นมาจากสคริปต์ ไม่มีใครลงวันที่ล่วงหน้าเพื่อค้างไว้บนสุดได้ ถ้าแก้โค้ดสคริปต์ภายหลัง ต้อง **Deploy > Manage deployments > แก้ไข > Version: New version** ที่อยู่ URL จะคงเดิม

สคริปต์รุ่น 11 พ.ย. 2026 ใช้กติกาหอเกียรติยศชุดใหม่ (หัวข้อหอเกียรติยศด้านล่าง) ถ้าตั้งสคริปต์รุ่นก่อนไว้แล้ว ให้วางโค้ดใหม่ทับแล้วทำ New version เสร็จแล้วเปิด Web app URL ต้องเห็น `"v":4` ระหว่างที่ยังไม่ได้อัปเดต หน้าเกมก็ซ่อนบันทึกที่กติกาไม่นับและเรียงลำดับใหม่เองอยู่แล้ว ต่างกันแค่สคริปต์รุ่นเก่ายังรับบันทึกเหล่านั้นเข้าชีต และส่งรายชื่อ 30 อันดับแรกตามคะแนนอย่างเดียว

สคริปต์รุ่น 5 (11 พ.ย. 2026) เริ่มหอเกียรติยศใหม่ทุกวันที่ 1 ของเดือนตามเวลาไทย คำขอแรกของเดือนใหม่ย้ายแถวของเดือนก่อน ๆ จากชีต `hof` ไปต่อท้ายชีต `hof-archive` พร้อมเดือนของแถวในคอลัมน์แรก ไม่มีแถวใดถูกลบทิ้ง และชีต `hof-archive` ไม่มีทางอ่านผ่าน Web app URL วันที่ของบันทึกมาจากนาฬิกาของสคริปต์ และบันทึกที่เคยขึ้นหอในเดือนก่อนส่งซ้ำเข้าเดือนใหม่ไม่ได้ วางโค้ดใหม่ทับแล้วทำ New version เสร็จแล้วเปิด Web app URL ต้องเห็น `"v":5` และ `"month"` เป็นเดือนปัจจุบัน ระหว่างที่ยังไม่ได้อัปเดต หน้าเกมก็แสดงเฉพาะผู้ชนะของเดือนนี้อยู่แล้ว

สคริปต์รุ่น 6 (15 พ.ย. 2026) เพิ่มสองอย่างให้เครื่องผู้พัฒนา คือรีเซ็ตหอเกียรติยศทั้งหอ และขอบันทึกการเดินของเกมที่ผู้ชนะคนหนึ่งเล่น เพื่อเล่นซ้ำตรวจผลกับการใช้ AI ช่วยเล่น (หัวข้อสถิติและหัวข้อหอเกียรติยศด้านล่าง) บันทึกใหม่ในชีต `hof` มีเวลาที่สคริปต์รับ (`t`) กับรหัสเกม (`gid`) ติดมาด้วย วางโค้ดใหม่ทับแล้วทำ New version เสร็จแล้วเปิด Web app URL ต้องเห็น `"v":6` และ `"reset":0` ระหว่างที่ยังไม่ได้อัปเดต ปุ่มรีเซ็ตและปุ่มตรวจในหอเกียรติยศจะบอกว่าสคริปต์ยังเป็นรุ่นก่อน ส่วนอื่นทำงานตามเดิม รวมถึงการตรวจเกมจากหน้าสถิติ

สคริปต์รุ่น 7 (16 พ.ย. 2026) ตรวจหอเกียรติยศทุกเที่ยงคืน หน้าเกมรุ่นนี้ส่งบันทึกการเดินของเกมไปพร้อมผลทุกครั้งที่ชัยชนะขึ้นหอ สคริปต์เก็บไว้ในชีต `hof-logs` แล้วทุกคืนไล่ดูผลในชีต `hof` ผลที่หาบันทึกการเดินของเกมนั้นไม่เจอเลย ทั้งในชีต `hof-logs` และในเกมที่จบของชีต `games` ถูกนำออกจากหอและบัญชีที่ส่งถูกระงับ (รายละเอียดในหัวข้อหอเกียรติยศด้านล่าง) ขั้นตอนอัปเดต:

1. อัปโหลดหน้าเกมรุ่นนี้ขึ้น GitHub ก่อนหรือหลังสคริปต์ก็ได้ หน้าเกมรุ่นนี้ใช้กับสคริปต์รุ่น 6 ได้ และสคริปต์รุ่น 7 เริ่มนับเมื่อผลแรกที่มีบันทึกการเดินติดมาเข้าหอ ก่อนหน้านั้นการตรวจทุกคืนไม่แตะอะไร
2. เปิด Apps Script ของชีต ลบโค้ดเก่า วางเนื้อหาใหม่จาก `scripts/hof-apps-script.gs` ใส่ Client ID ที่ `GOOGLE_CLIENT_ID` เหมือนเดิม กดบันทึก แล้วทำ New version เปิด Web app URL ต้องเห็น `"v":7`
3. กด **Project Settings** (รูปเฟือง) ดูช่อง **Time zone** ให้เป็นเวลากรุงเทพ `(GMT+07:00) Bangkok` ถ้ายังไม่ใช่ให้เลือกแล้วบันทึก ทริกเกอร์รายวันใช้เขตเวลานี้
4. กด **Triggers** (รูปนาฬิกาปลุกทางซ้าย) > **Add Trigger** ช่อง Choose which function to run เลือก `nightlyHofCheck` ช่อง Select event source เลือก **Time-driven** ช่อง Select type of time based trigger เลือก **Day timer** ช่อง Select time of day เลือก **Midnight to 1am** แล้วกด Save ถ้า Google ขอสิทธิ์อีกครั้ง ให้อนุญาตแบบเดียวกับตอนตั้งครั้งแรก
5. ผลของแต่ละคืนดูได้ที่ **Executions** ใน Apps Script หรือที่กล่อง **ตรวจหอเกียรติยศทุกคืน** ในหน้าสถิติบนเครื่องผู้พัฒนา

ค่าที่ปรับได้ใน `CONFIG` ของสคริปต์: `NIGHTLY` (ตั้ง `false` เพื่อพักการตรวจโดยไม่ต้องลบทริกเกอร์) `NIGHTLY_GRACE_DAYS` (จำนวนวันผ่อนผันหลังผลแรกที่มีบันทึกการเดิน ค่าเริ่ม 2 วัน ช่วงนี้ผลที่ไม่มีบันทึกการเดินถูกนำออกอย่างเดียว ไม่ระงับบัญชี เพราะหน้าเกมรุ่นเก่าที่เปิดค้างไว้ยังส่งผลแบบไม่มีบันทึก) และ `BLOCK_NOTICE` (ข้อความที่บัญชีที่ถูกระงับเห็น)

สคริปต์รุ่น 8 (17 พ.ย. 2026) กันการยัดข้อมูล ไฟล์ `scripts/hof-apps-script.gs` รุ่นนี้ยาวราว 460 KB เพราะมีเอนจิน AI ข้อมูลการ์ด และชุดกฎชุดเดียวกับหน้าเกมต่อท้ายอยู่ (ส่วนที่ build.py สร้างจากไฟล์ของหน้าเกม ห้ามแก้เอง) ทุกผลที่ส่งเข้าหอ สคริปต์เล่นเกมนั้นซ้ำทั้งเกมจากบันทึกการเดินก่อนรับ ผลที่เล่นซ้ำแล้วผู้ชนะ คะแนน หรือตัวเลขใดไม่ตรงกับที่ส่งมาถูกปฏิเสธทันที (รายละเอียดในหัวข้อหอเกียรติยศด้านล่าง) วางโค้ดใหม่ทับทั้งไฟล์ ใส่ Client ID เหมือนเดิม แล้วทำ New version เปิด Web app URL ต้องเห็น `"v":8` และ `"eng"` เป็นรหัสเดียวกับที่หน้าสถิติบนเครื่องผู้พัฒนาบอกว่าเป็นของหน้านี้ ทริกเกอร์ของรุ่น 7 ใช้ต่อได้ ไม่ต้องตั้งใหม่

**ทุกครั้งที่แก้กติกา เอนจิน AI หรือข้อมูลการ์ด** รหัส `ENGINE_STAMP` ท้ายไฟล์สคริปต์จะเปลี่ยนตาม ต้องอัปหน้าเกมกับวางไฟล์สคริปต์ใหม่ทั้งไฟล์คู่กันทุกครั้ง ถ้าสคริปต์ยังเป็นเอนจินเก่า ผู้ชนะจากหน้าใหม่ที่เกมเปลี่ยนไปเพราะกติกาใหม่จะถูกปฏิเสธ (ไม่นับเป็นความผิด) หน้าหอเกียรติยศและหน้าสถิติบนเครื่องผู้พัฒนาขึ้นแถบเตือนสีแดงเมื่อสองฝั่งไม่ตรงกัน การแก้หน้าเกมส่วนอื่นที่ไม่แตะสามอย่างนี้ไม่เปลี่ยนรหัส

ค่าที่เพิ่มใน `CONFIG`: `REPLAY` (ตั้ง `false` เพื่อพักการเล่นซ้ำ) `REPLAY_MS` (เวลานานสุดที่การเล่นซ้ำหนึ่งเกมใช้ได้ เกินนี้ผู้เล่นได้คำตอบว่ายุ่งให้ลองใหม่) `REFUSALS_TO_BLOCK` กับ `REFUSAL_DAYS` (ค่าเริ่ม ปฏิเสธ 3 ครั้งใน 7 วันจึงระงับ) `MAX_BODY` (ขนาดคำขอสูงสุด) `SIGNINS_PER_MIN` (จำนวนการตรวจลงชื่อเข้าใช้กับ Google ต่อนาทีทั้งเว็บ) `NIGHT_REPLAY_MS` (เวลาที่การตรวจทุกคืนใช้เล่นซ้ำผลที่ขึ้นหอก่อนรุ่นนี้) และ `REQUIRE_LOG` (ตั้ง `false` เพื่อกลับไปรับผลที่ไม่มีบันทึกการเดินแบบรุ่น 7)

ถ้าเคยตั้งสคริปต์รุ่นก่อน (รุ่นที่มีแต่หอเกียรติยศ) ไว้แล้ว: เปิด Apps Script ของชีตเดิม ลบโค้ดเก่าทั้งหมด วางเนื้อหาใหม่จาก `scripts/hof-apps-script.gs` ใส่ Client ID ที่ `GOOGLE_CLIENT_ID` เหมือนเดิม กดบันทึก แล้วทำ New version ตามย่อหน้าก่อน ลานความคิดเห็น ปุ่มลบ และสถิติการเล่นจะใช้ได้กับที่อยู่ URL เดิม

## สถิติการเล่น (เห็นเฉพาะผู้พัฒนา)

เมื่อ `config.js` มีที่อยู่สคริปต์ หน้าเกมส่งสถิติให้สคริปต์ตัวเดียวกัน ผู้เล่นทั่วไปไม่เห็นข้อมูลชุดนี้ และไม่มีที่อยู่สาธารณะใดเปิดให้อ่าน

- **จำนวนคนเข้าต่อวัน** เบราว์เซอร์หนึ่งส่งสัญญาณวันละครั้ง สคริปต์บวกยอดของวันนั้นในชีต `daily` แยกสมาชิก (ลงชื่อเข้าใช้ตอนเข้า) กับผู้มาเยือน และนับเครื่องผู้พัฒนาไว้อีกช่อง สคริปต์ไม่เก็บรายการการเข้าชม
- **เกมที่เล่น** ทุกเกมที่เริ่ม จบ หรือออกกลางคัน เป็นหนึ่งแถวในชีต `games` มีโหมด ชุดกฎ จำนวนรัฐ ระดับ AI รอบที่ไปถึง เวลาที่เล่น คะแนนตอนจบ การ์ดวิจัยและการ์ดทหารที่แต่ละรัฐเลือก (แยกผู้เล่นกับ AI) รหัสสุ่มของเบราว์เซอร์ และแฮชของรหัสบัญชีถ้าเป็นสมาชิก
- **บันทึกการเล่น** แถวของเกมที่จบหรือออกกลางคันเก็บบันทึกการเดิน (ซีดกับทุกการตัดสินใจของผู้เล่น) พอให้เล่นเกมนั้นซ้ำได้ทั้งเกม

ดูสถิติได้ที่ **เมนู > สถิติผู้เล่น** บนเครื่องผู้พัฒนา หน้านั้นมีจำนวนคนเข้าวันนี้ เฉลี่ยต่อวัน และรายวัน เกมที่เริ่ม เล่นจบ ออกกลางคัน คนที่เล่นจบแยกสมาชิกกับผู้มาเยือน การ์ดวิจัยและการ์ดทหารที่ถูกเลือกมากที่สุดในแต่ละชุดกฎ (นับจากเกมที่เล่นจบ) และรายการเกมล่าสุด ปุ่ม **ดูเกม** สร้างเกมนั้นขึ้นใหม่จากบันทึกการเดินแล้วเล่นถึงตอนจบ หรือหยุดตรงที่ผู้เล่นออกไป ระหว่างดูไม่มีอะไรถูกบันทึกหรือส่งเพิ่ม เปิดชีตใน Google Sheets ดูข้อมูลดิบได้เช่นกัน

**ตรวจการใช้ AI ช่วยเล่น** (15 พ.ย. 2026) หน้าสถิติมีกล่องตรวจเหนือรายการเกมล่าสุด การตรวจดูเฉพาะผู้ชนะ ปุ่ม **ตรวจ AI** จึงมีเฉพาะท้ายแถวของเกมที่ผู้เล่นชนะ เกมที่ AI ชนะ เกมที่ออกกลางคัน และผู้เล่นคนอื่นที่โต๊ะไม่ถูกตรวจ กดแล้วหน้าเกมเล่นเกมนั้นซ้ำจากบันทึกการเดินบนเครื่องผู้พัฒนา แล้วเทียบทุกการตัดสินใจของผู้ชนะที่มีทางเลือกมากกว่าหนึ่งทางกับคำแนะนำของ AI ในเกม (คำแนะนำแบบเดียวกับโหมดสอนเล่น สไตล์สมดุล ระดับปกติ คิดด้วยสุ่มของตัวเองจึงไม่แตะเกม) ผลขึ้นเป็นป้ายท้ายแถว เช่น ตรงกับ AI 68% ป้ายสีส้ม **ถึงเกณฑ์ธง** ขึ้นเมื่อตรงตั้งแต่ร้อยละที่ตั้งไว้ (ค่าเริ่ม 90% ปรับได้ในกล่องตรวจ) และผู้ชนะตัดสินใจจริงอย่างน้อย 40 ครั้ง ป้ายสีแดง **ผลไม่ตรง** แปลว่าเล่นซ้ำแล้วคะแนนไม่ตรงกับที่หน้าเกมรายงาน กดป้ายเพื่อดูแยกตามชนิดการตัดสินใจ พร้อมปุ่มดูเกม ปุ่ม **ตรวจทุกเกมที่ผู้เล่นชนะ** ไล่ตรวจเกมที่ผู้เล่นชนะในรายการ เกมละรายงานเดียว ไม่นับเกมสอนเล่นและเกมของเครื่องผู้พัฒนา แล้วสรุปการกระจายของผู้ชนะ รายชื่อที่ถึงเกณฑ์ เกมที่ผลไม่ตรง และเกมที่เปิดผู้ช่วย AI แยกไว้ต่างหาก

ค่าอ้างอิงจากการทดลอง 15 พ.ย. (แบบละ 8 เกม เกมละราว 110 การตัดสินใจจริง): เล่นตามคำแนะนำ เช่นเปิดเล่นอัตโนมัติจากคอนโซล ตรง 100% AI ของเกมสไตล์ต่าง ๆ เล่นเองตรง 92 ถึง 97% (รายเกม 89 ถึง 99%) ผู้เล่นที่สุ่มเลือกตรงราว 25% ยังไม่มีข้อมูลของผู้เล่นจริง เกณฑ์ 90% จึงเป็นค่าตั้งต้น ควรดูการกระจายจากเกมจริงก่อนตัดสิน ผลนี้เป็นสัญญาณให้เปิดดูเกมต่อ ผู้เล่นเก่งที่คิดแบบเดียวกับ AI ก็ตรงสูงได้เช่นกัน และ AI ภายนอกเกมอย่างแชตบอตตรวจด้วยวิธีนี้ไม่ได้ ผลตรวจอยู่บนเครื่องผู้พัฒนาเท่านั้น ไม่มีหน้าสาธารณะใดแสดง และเกมไม่เก็บเวลาที่ใช้คิดหรือการสลับแท็บ

สถิติไม่มีอีเมล ไม่มีชื่อบัญชี และสคริปต์ไม่เห็นที่อยู่ IP ผู้เล่นปิดการส่งได้ที่ **ตั้งค่า > ส่งสถิติการเล่น** และเบราว์เซอร์ที่ส่งสัญญาณ Global Privacy Control หรือ Do Not Track จะไม่ส่งสถิติเลย ส่วนชัยชนะที่ขึ้นหอเกียรติยศออนไลน์ส่งบันทึกการเดินของเกมนั้นไปด้วยเสมอ ไม่ขึ้นกับสวิตช์นี้ เพราะเป็นหลักฐานของผลที่ประกาศต่อสาธารณะ (หัวข้อ 4 ของ `privacy.html`) แถวของเกมที่เก่ากว่า 365 วันถูกลบตอนผู้พัฒนาเปิดหน้าสถิติ (ปรับที่ `KEEP_DAYS`) ตั้ง `STATS: false` ในสคริปต์เพื่อหยุดเก็บทั้งหมด หัวข้อ 5 ของ `privacy.html` บอกผู้เล่นเรื่องนี้ไว้ ถ้าเปลี่ยนสิ่งที่เก็บ ให้แก้นโยบายตามด้วย

ข้อจำกัด: สคริปต์ยืนยันได้ว่าผู้ส่งเป็นบัญชี Google จริงหรือเครื่องผู้พัฒนา แต่ยืนยันไม่ได้ว่าเกมเล่นจริง คนที่เขียนโปรแกรมเองยังส่งบันทึกปลอมที่ผ่านการตรวจได้ เจ้าของเกมจึงยังต้องคอยดูชีต ปุ่มตรวจในหอเกียรติยศช่วยได้ส่วนหนึ่ง รายชื่อที่ไม่มีบันทึกการเดิน หรือเล่นซ้ำแล้วผลไม่ตรง ควรเปิดดูก่อน ตั้งแต่สคริปต์รุ่น 7 รายชื่อที่ไม่มีบันทึกการเดินออกจากหอเองทุกคืน และตั้งแต่รุ่น 8 ผลที่ไม่ตรงกับเกมที่เล่นจริงเข้าหอไม่ได้เลย สิ่งที่การเล่นซ้ำกันไม่ได้คือเกมที่เล่นจริงทั้งเกมแต่ให้ AI ภายนอกคิดแทน ผลแบบนั้นเป็นเกมจริงตามกติกาทุกตา ด่านที่จับได้คือปุ่มตรวจ AI ซึ่งวัดว่าการตัดสินใจของผู้ชนะตรงกับ AI ของเกมกี่ร้อยละ ปุ่มส่งผ่าน GitHub ยังใช้ได้เมื่อไม่ได้ตั้งที่อยู่นี้ หรือเมื่อส่งออนไลน์ไม่สำเร็จ

## ผู้เล่นออนไลน์และความยากของ AI

- ปุ่ม **ออนไลน์ N คน** มุมล่างซ้าย (มุมขวาบนระหว่างเล่น) เปิดรายชื่อทุกคนที่เปิดหน้าเกมอยู่ ทั้งสมาชิกที่ลงชื่อเข้าใช้และผู้เยี่ยมชม พร้อมสิ่งที่แต่ละคนทำอยู่ ระบบนี้ใช้ห้องล็อบบี้เดียวกับการเล่นออนไลน์ เบราว์เซอร์จึงต่อรีเลย์ Nostr และต่อตรงกับเบราว์เซอร์อื่นด้วย WebRTC ซึ่งทำให้เครื่องที่ต่อกันเห็นที่อยู่เครือข่ายของกันและกัน ผู้เล่นปิดได้ที่ **ตั้งค่า > แสดงตัวว่าออนไลน์**
- ตอนตั้งโต๊ะเลือก **ความยาก AI** ได้สามระดับ: **ง่าย** AI พลาดบ่อย ชัยชนะไม่ขึ้นหอเกียรติยศ **ปกติ** แบบเดิม **ยาก** AI ไม่ลังเล และได้ความชอบธรรม 2 ทุกต้นยุคจากบารมีตระกูลเก่า (ขึ้นในบันทึกเกมและป้ายที่มาของคะแนน) ผู้ชนะระดับนี้ขึ้นหอเกียรติยศก่อนระดับอื่น ในห้องออนไลน์ผู้สร้างห้องเลือกระดับให้ที่นั่ง AI
- ปุ่ม AI แนะนำ มีในโหมดสอนเล่น และในเกมกับ AI ที่ติ๊กช่อง **ผู้ช่วย AI** ตอนตั้งโต๊ะ (15 พ.ย. 2026) เกมที่เปิดผู้ช่วยมีปุ่ม AI แนะนำในทุกการตัดสินใจ ฟอร์มวางแรงงานกรอกตามที่ AI แนะนำไว้ก่อน และตั้งให้ AI วางแรงงานแทนได้ แถบบนของโต๊ะมีป้าย ผู้ช่วย AI ชัยชนะในเกมที่เปิดผู้ช่วยไม่ขึ้นหอเกียรติยศ และหน้าจบเกมบอกไว้ เกมออนไลน์ไม่มีตัวช่วยจาก AI
- ตอนตั้งโต๊ะเลือก **โหมด** ได้สองแบบ: **ปกติ** และ **รัฐที่แตกแยก (Asymmetric)** ซึ่งยังเป็นโหมดทดลอง ก่อนเริ่มเกมทุกรัฐจั่วการ์ดผู้สนับสนุน 5 ใบ เลือกเก็บ 1 ใบ แล้วได้ความสามารถเฉพาะตัวไปทั้งเกม การ์ดทั้ง 30 ใบอยู่ในหน้าวิธีเล่น เกมออนไลน์ใช้โหมดที่ผู้สร้างห้องเลือก ห้องในล็อบบี้และแถวในหอเกียรติยศของโหมดนี้มีชื่อโหมดกำกับ

## เล่นออนไลน์กับเพื่อน

1. ส่งลิงก์หน้าเกมให้เพื่อน ทุกคนกรอกชื่อผู้นำ ตั้งชื่อรัฐหรือปล่อยให้สุ่มชื่ออัลธาลานี และวาดธงรัฐ
2. คนหนึ่งเข้า **เล่นออนไลน์กับเพื่อน** แล้วกด **สร้างห้องใหม่** จากนั้นส่งรหัสห้อง หรือกด **คัดลอกลิงก์ชวนเพื่อน** ถ้าไม่อยากให้คนที่ไม่ได้ชวนเข้ามา ให้กรอก **รหัสผ่านห้อง** ข้างปุ่มสร้างห้อง หรือตั้งในหน้าห้องภายหลัง ห้องที่ตั้งรหัสผ่านขึ้นรูปกุญแจในล็อบบี้ คนที่จะเข้าห้องต้องกรอกรหัสนี้ ลิงก์ชวนไม่มีรหัสผ่านติดไปด้วย ให้ส่งรหัสให้เพื่อนแยกกัน
3. เพื่อนกดเข้าห้องจากรายการห้อง หรือกรอกรหัส เข้าห้องแล้วกด **นั่งที่นี่** บนเก้าอี้ว่างหนึ่งตัว (ผู้สร้างห้องนั่งเก้าอี้ตัวแรกให้เอง) ย้ายเก้าอี้หรือกด **ลุกจากที่นั่ง** ได้จนกว่าเกมเริ่ม ผู้สร้างห้องกด **ทอยลูกเต๋าและเริ่มเกม** ที่นั่งที่ยังว่างให้ AI เล่นแทน คนที่ยังยืนอยู่ได้ดูเกม
4. ระหว่างเกมกดปุ่ม **แชท** มุมบนเพื่อคุยกัน
5. จบเกมแล้วหน้าจบเกมมีปุ่มเดียวคือ **กลับห้อง** ทุกคนกลับมาที่ห้องเดิม ที่นั่ง แชท และรหัสผ่านยังอยู่ ผู้สร้างห้องปรับค่าแล้วเริ่มเกมถัดไปได้เลย ใครยังดูหน้าจบเกมอยู่ตอนผู้สร้างห้องเริ่มเกมใหม่จะเข้าเกมใหม่เอง

เบื้องหลัง: เบราว์เซอร์ของผู้เล่นหาเจอกันผ่านรีเลย์ Nostr สาธารณะ แล้วต่อตรงกันด้วย WebRTC ทุกเครื่องรันเอนจินเดียวกันจากซีดเดียวกัน และส่งกันเฉพาะคำตอบของผู้เล่นคน ผลเกมจึงตรงกันทุกเครื่อง

- **แชทล็อบบี้ล้างทุกวัน** ข้อความในแชทล็อบบี้ส่งถึงกันตรง ๆ ระหว่างหน้าเกมที่เปิดอยู่ ไม่ถูกเก็บที่ไหน คนที่เพิ่งเปิดหน้าจึงไม่เห็นข้อความเก่า และหน้าที่เปิดค้างข้ามเที่ยงคืนตามเวลาไทยล้างข้อความของวันก่อนเอง แชทในห้องเกมอยู่กับห้องจนห้องปิด
- **ถ้ามีคนหลุด** เกมรอ 20 วินาที แล้วให้ AI เล่นแทนที่นั่งนั้น เมื่อเขาเปิดหน้าเกมใหม่ เมนูจะมีปุ่ม **กลับเข้าห้องออนไลน์** กดแล้วเครื่องจะขอบันทึกเกมจากเพื่อน เล่นย้อนให้ทัน แล้วได้ที่นั่งคืน
- **ห้องถูกลบทันทีที่ผู้เล่นคนสุดท้ายออก** ผู้เล่นคนสุดท้ายที่กดออกจากห้องเห็นคำเตือนก่อน ออกแล้วบันทึกห้องในเครื่องถูกลบ และเบราว์เซอร์อื่นในล็อบบี้ที่เคยเล่นห้องนั้นลบปุ่ม **กลับเข้าห้องออนไลน์** ของห้องนั้นตามทันที ใครกดกลับเข้าห้องที่ไม่มีผู้เล่นเหลือแล้ว จะเห็นว่าห้องปิดแล้วและบันทึกถูกลบ ข้อยกเว้นเดียวคือเบราว์เซอร์ที่หลุดไปเองไม่ถึงนาทีครึ่ง เช่น กดรีเฟรชหรือเน็ตสะดุด ซึ่งยังเล่นต่อจากบันทึกในเครื่องได้ ส่วนการกดออกจากห้องเองไม่เข้าข้อยกเว้นนี้
- **ระหว่างรอผู้สร้างห้อง** หน้าห้องบอกว่าส่งคำทักไปกี่ครั้งและต่อกับผู้เล่นในห้องได้กี่คน เครื่องส่งคำทักซ้ำทุกสองวินาทีครึ่งจนผู้สร้างห้องตอบ คำขอนั่งก็ส่งซ้ำจนรายชื่อที่นั่งยืนยัน ผู้สร้างห้องส่งรายชื่อที่นั่งให้ทุกคนทุกห้าวินาที ถ้ารอนานมีปุ่ม **เชื่อมต่อใหม่** คนที่หลุดก่อนเริ่มเกมยังได้เก้าอี้คืนถ้ากลับมาภายใน 20 วินาที
- **รหัสผ่านห้อง** ห้องที่ล็อกใช้ช่องทางที่ตั้งชื่อจากรหัสห้องรวมกับรหัสผ่าน เครื่องที่ไม่มีรหัสผ่านจึงหาห้องไม่เจอเลย ไม่เห็นที่นั่งหรือแชท และส่งอะไรเข้าห้องไม่ได้ ถ้ากรอกผิด หน้าห้องจะค้างที่กำลังติดต่อผู้สร้างห้องแล้วให้กรอกรหัสผ่านใหม่ ผู้สร้างห้องเปลี่ยนหรือลบรหัสผ่านได้ก่อนเริ่มเกม คนที่นั่งอยู่แล้วย้ายตามไปเอง คนที่ยืนดูต้องกรอกรหัสใหม่ ตัวรหัสผ่านไม่ถูกส่งไปที่ใดและไม่ถูกบันทึกลงเครื่อง หน้าห้องของผู้สร้างห้องแสดงไว้ให้บอกเพื่อนเท่านั้น
- **หน้าเกมต่างรุ่น** ทุกเครื่องในห้องต้องใช้หน้าเกมรุ่นเดียวกัน ถ้าผู้สร้างห้องใช้กฎที่หน้าเกมของผู้เข้าร่วมยังไม่มี หน้าห้องของผู้เข้าร่วมจะบอกให้กด Ctrl+F5 เพื่อโหลดหน้าเกมใหม่แล้วเข้าห้องอีกครั้ง เกมจึงไม่เริ่มบนกติกาที่ไม่ตรงกัน
- **บัญชีเดียวนั่งได้ที่เดียว** บัญชีเดียวกันเปิดห้องจากสองหน้าต่าง ที่นั่งย้ายไปอยู่กับหน้าต่างล่าสุด ถ้าเป็นบัญชีของผู้สร้างห้องเอง หน้าต่างที่สองถูกปฏิเสธพร้อมคำอธิบาย ให้ออกจากระบบในแท็บนั้นเพื่อเข้าแบบผู้เยี่ยมชม
- **รีเลย์** เกมใช้รีเลย์ Nostr 8 ตัวที่ตรวจแล้วว่าตอบภายในราวสองวินาที (8 พ.ย. 2026) เปลี่ยนชุดรีเลย์ได้ที่ `relays` ใน `config.js` โดยไม่ต้องแก้ `index.html` ทุกเครื่องต้องใช้ชุดเดียวกันจึงจะเจอกัน
- **ถ้าเชื่อมต่อไม่ได้** เครือข่ายบางแห่ง เช่น เครือข่ายบริษัท มหาวิทยาลัย หรือมือถือบางค่าย กั้นการต่อตรงแบบ WebRTC ทางแก้คือใช้ TURN server (มีบริการฟรีแบบจำกัดปริมาณ เช่น Cloudflare และ Open Relay ของ Metered) แล้วใส่ค่าที่ `turn` ใน `config.js`:
  ```js
  turn: [{ urls: 'turn:ที่อยู่:3478', username: 'ชื่อ', credential: 'รหัส' }],
  ```
  หรือใส่แท็ก `<meta name="fed-turn" content='[...]'>` ใน `<head>` ของ `index.html` แบบเดิมก็ได้
- **ทดสอบคนเดียวสองแท็บ** เปิดหน้าเกมสองแท็บ ให้แท็บหนึ่งลงชื่อเข้าใช้ (หรือเข้าระบบผู้พัฒนา) อีกแท็บกด **ออกจากระบบ** สองแท็บจะเป็นผู้เล่นคนละคน ทดสอบแบบไม่ต่อรีเลย์ได้ด้วย `index.html?net=local` สองแท็บในเบราว์เซอร์เดียวกัน ซึ่งคุยกันผ่าน BroadcastChannel

## หอเกียรติยศและลานความคิดเห็น

- **หอเกียรติยศรายเดือน** (11 พ.ย. 2026) หอเกียรติยศเริ่มใหม่ทุกวันที่ 1 เวลา 00:00 น. ตามเวลาไทย ทุกเครื่องใช้เวลาไทยเหมือนกันไม่ว่าผู้เล่นอยู่ที่ไหน หน้าหอเกียรติยศบอกชื่อเดือนที่แสดง ผลของเดือนก่อนหายจากหน้าเกม จากเครื่องผู้เล่น และจากรายชื่อที่ผู้เล่นส่งต่อกันในล็อบบี้ ส่วนไฟล์ `data/hall-of-fame.json` ปล่อยเดือนก่อนออกตอน Action บันทึกผลถัดไป และ Action ลงวันที่ผลตามเวลาที่มันทำงาน
- กติกาหอเกียรติยศ (11 พ.ย. 2026): เกมกับ AI ขึ้นหอได้เฉพาะโต๊ะ 4 รัฐที่ AI ระดับปกติหรือยาก ชัยชนะกับ AI ระดับง่ายหรือที่โต๊ะ 3 รัฐไม่ขึ้นหอ การเรียงให้ผู้ชนะที่เล่นกับ AI ระดับยากขึ้นก่อน จากนั้นจึงเรียงตามคะแนนสุทธิ เกมออนไลน์ที่ไม่มีที่นั่ง AI เลยเรียงตามคะแนนร่วมกับเกมที่ AI ระดับปกติ บันทึกเก่าที่กติกาไม่นับยังอยู่ในชีตหรือไฟล์ แต่หน้าเกมไม่แสดง
- จบเกมแล้ว ถ้าผู้ชนะเป็นผู้เล่น (ไม่นับ AI และโหมดสอนเล่น) และลงชื่อเข้าใช้แล้ว ผลจะบันทึกในเครื่อง ส่งให้ผู้เล่นที่ออนไลน์อยู่ และขึ้นหอเกียรติยศอัตโนมัติทันทีถ้าตั้งไว้ตามหัวข้อด้านบน หน้าจบเกมไม่ขึ้นข้อความว่าบันทึกแล้ว จะมีข้อความเฉพาะตอนที่ผู้เล่นต้องลงชื่อเข้าใช้หรือส่งซ้ำ บันทึกมีคะแนน จำนวนการ์ดวิจัย การ์ดทหาร และโครงการ พร้อมการวิเคราะห์ว่ารัฐนั้นเล่นสายใด ซึ่งอ่านจากแอคชันที่เลือก การ์ดนวัตกรรม และการ์ดวัฒนธรรมตลอดเกมเทียบกับโต๊ะทั่วไปของฉบับ 0.4.4 ห้าแกน (นักขยายดินแดน พาณิชย์ ทหาร วิทยาการ ศาสนา) แกนหลักคู่กับแกนรองมีชื่อระบอบของตัวเอง และคำนำหน้าแนวธุรกิจหรือราชวงศ์ของผู้นำเปลี่ยนชื่อเรียกบางแบบ หอเกียรติยศเรียกทุกบันทึกด้วยชื่อชุดปัจจุบัน บันทึกที่จบก่อนเปลี่ยนชื่อใช้ผลอ่านเดิมกับชื่อชุดใหม่ ชี้ที่ชื่อเพื่อดูชื่อตอนจบเกม
- ปุ่ม **ส่งเข้าหอเกียรติยศถาวรผ่าน GitHub** เปิดหน้า New issue ที่กรอกข้อมูลไว้แล้ว ผู้ส่งต้องล็อกอิน GitHub แล้วกด Submit Action จะตรวจข้อมูล เพิ่มลง `data/hall-of-fame.json` ตอบกลับ แล้วปิด issue หน้าเกมอ่านไฟล์นี้จาก `raw.githubusercontent.com` จึงเห็นภายในไม่กี่นาที
- **ลานความคิดเห็น** กดส่งแล้วความคิดเห็นขึ้นลานทันที หน้าเกมไม่เปิดหน้าอื่นและไม่ขึ้นข้อความใด เมื่อตั้งสคริปต์ตามหัวข้อด้านบนแล้ว สคริปต์เก็บความคิดเห็นไว้ให้ทุกคนที่เปิดลานภายหลังเห็น ผู้เขียนต้องลงชื่อเข้าใช้ Google (หรือเป็นเครื่องผู้พัฒนา) ผู้เยี่ยมชมเห็นปุ่มลงชื่อเข้าใช้แทนช่องเขียน ถ้าส่งไม่สำเร็จ ใต้ช่องเขียนจึงบอกสาเหตุพร้อมปุ่มส่งอีกครั้ง ถ้ายังไม่ได้ตั้งสคริปต์ ความคิดเห็นอยู่ในเบราว์เซอร์ของผู้เขียนและถึงผู้เล่นที่ออนไลน์อยู่ตอนนั้นเท่านั้น
- ผู้เขียนให้ดาว 1 ถึง 5 ดวงได้หรือไม่ให้ก็ได้ ความคิดเห็นที่ไม่ได้ให้ดาวไม่ขึ้นดาว หัวลานแสดงดาวเฉลี่ยโดยนับดาวล่าสุดของแต่ละคนครั้งเดียว ความคิดเห็นที่ผ่านสคริปต์นับตามบัญชี เพราะสคริปต์เป็นผู้ติดป้ายผู้เขียนเอง
- **ผู้พัฒนาลบรายการได้** บนเครื่องผู้พัฒนา ทุกแถวในหอเกียรติยศและทุกความคิดเห็นมีปุ่ม **ลบ** กดแล้วเกมถามยืนยันก่อน ลบรายชื่อแล้วรายชื่อถัดไปเลื่อนขึ้นแทน สคริปต์ลบแถวในชีตและจดรายการนั้นไว้ในชีต `removed` ทุกหน้าเกมที่อ่านสคริปต์จึงซ่อนรายการนั้นด้วย แม้รายการจะยังอยู่ในไฟล์ `data` ของคลังหรือค้างอยู่ในเบราว์เซอร์ของผู้เล่น บันทึกที่ถูกลบซึ่งส่งเข้ามาซ้ำจะไม่กลับขึ้นมา ถ้ายังไม่ได้ตั้งสคริปต์ การลบซ่อนรายการได้เฉพาะในเครื่องผู้พัฒนา ส่วนการลบให้ทุกคนต้องแก้ไฟล์ `data/hall-of-fame.json` หรือ `data/comments.json` บน GitHub
- **ตรวจรายชื่อกับเกมที่เล่นจริง** (15 พ.ย. 2026) บนเครื่องผู้พัฒนา หน้าหอเกียรติยศมีแถบหลังบ้าน และทุกแถวมีปุ่ม **ตรวจ AI** เหนือปุ่มลบ กดแล้วหน้าเกมขอบันทึกการเดินของเกมนั้นจากสคริปต์ (หาด้วยรหัสเกม ถ้าเป็นบันทึกเก่าที่ไม่มีรหัสเกม หาด้วยชุดกฎ จำนวนรัฐ ชื่อรัฐ คะแนน และซีด) เล่นซ้ำ แล้วขึ้นป้ายใต้ชื่อรัฐ: ร้อยละที่ตรงกับ AI ของผู้ชนะคนเดียว (คนอื่นที่โต๊ะไม่ถูกตรวจ) **ผลไม่ตรง** เมื่อเล่นซ้ำแล้วผู้ชนะหรือคะแนนไม่ตรงกับบันทึก หรือรัฐในบันทึกไม่ได้อยู่ในเกมนั้น หรือ **ตรวจไม่ได้: ไม่มีบันทึกการเดิน** เมื่อรายชื่อขึ้นหอก่อนสคริปต์รุ่น 7 โดยผู้ชนะปิดการส่งสถิติ หรือรายชื่อมาจากไฟล์ในคลังหรือจากผู้เล่นออนไลน์ ปุ่ม **ตรวจ AI ทั้ง N อันดับ** ตรวจทุกแถวที่แสดง ผู้เล่นคนอื่นไม่เห็นปุ่มหรือป้ายเหล่านี้ ผู้พัฒนาตัดสินเองว่าจะลบรายชื่อใดด้วยปุ่มลบเดิม ใช้ได้เมื่อสคริปต์เป็นรุ่น 6
- **ตรวจหอเกียรติยศทุกเที่ยงคืน** (16 พ.ย. 2026) ชัยชนะที่ขึ้นหอออนไลน์มีบันทึกการเดินของเกมนั้นติดไปด้วยเสมอ แม้ผู้เล่นปิดการส่งสถิติ สคริปต์รับบันทึกการเดินเฉพาะที่เป็นของเกมนั้นจริง (ซีด ชุดกฎ จำนวนรัฐ และรัฐที่ชนะเป็นที่นั่งของคน) ทุกคืนช่วงเที่ยงคืนถึงตีหนึ่ง ทริกเกอร์เรียก `nightlyHofCheck` ไล่ดูทุกผลในหอที่เข้ามาตั้งแต่ผลแรกที่มีบันทึกการเดินติดมา ผลที่หาบันทึกการเดินของเกมนั้นไม่เจอเลย (ไม่มีทั้งในชีต `hof-logs` และในเกมที่จบของชีต `games`) แปลว่าไม่ได้ส่งมาจากหน้าเกม ผลนั้นย้ายไปชีต `hof-flagged` พร้อมเหตุและข้อมูลเต็ม ถูกจดในชีต `removed` ให้ทุกหน้าเกมซ่อน บัญชีที่ส่งถูกระงับในชีต `blocked` และผลอื่นของบัญชีนั้นในหอออกไปด้วย บัญชีที่ถูกระงับส่งผลเข้าหอและเขียนความคิดเห็นไม่ได้ และเห็นข้อความ `BLOCK_NOTICE` (ค่าเริ่ม: ระบบตรวจพบว่ามีการใช้ AI และพยายามแทรกแซงระบบ ผลของบัญชีนี้ถูกนำออกจากหอเกียรติยศ และบัญชีถูกระงับจากหอเกียรติยศกับลานความคิดเห็น) บนหน้าหอเกียรติยศ บนลานความคิดเห็นแทนช่องเขียน และบนหน้าจบเกมเมื่อชนะ ผู้เล่นคนอื่นไม่เห็นข้อความนี้ ผลที่ขึ้นหอก่อนการตรวจเริ่มนับไม่ถูกแตะ เครื่องผู้พัฒนาไม่ถูกระงับ (ผลที่ไม่มีบันทึกการเดินของเครื่องผู้พัฒนาถูกนำออกอย่างเดียว) ผลที่ส่งเข้ามาวันสุดท้ายของเดือนแล้วถูกย้ายไปชีต `hof-archive` ก่อนทริกเกอร์ทำงาน ถูกตรวจที่ชีตนั้นครั้งเดียว ปลดระงับได้ที่ปุ่ม **ปลดระงับ** ในกล่องตรวจหอเกียรติยศทุกคืนของหน้าสถิติ หรือลบแถวในชีต `blocked` ผลที่ถูกนำออกไปแล้วไม่กลับเข้าหอเอง ข้อมูลเต็มของผลนั้นอยู่ในชีต `hof-flagged` ถ้าต้องคืน ให้ลบแถวของผลนั้นในชีต `removed` แล้วใส่แถวกลับในชีต `hof` เอง
- **หอเกียรติยศเมื่อตั้งสคริปต์แล้ว** (16 พ.ย. 2026) หน้าหอเกียรติยศของทุกเครื่องรวมเฉพาะรายชื่อจากสคริปต์ ไฟล์ในคลัง GitHub และชัยชนะของเครื่องนั้นเองที่ยังส่งไม่ถึง รายชื่อที่ได้มาจากผู้เล่นออนไลน์คนอื่นไม่ขึ้น เพราะไม่ได้ผ่านสคริปต์ การตรวจทุกคืนจึงไปไม่ถึงรายชื่อเหล่านั้น บัญชีที่ถูกระงับไม่เห็นชัยชนะของตัวเองที่ส่งไม่ผ่าน ถ้าไม่ได้ตั้งสคริปต์ หอเกียรติยศรวมรายชื่อจากผู้เล่นออนไลน์ตามเดิม
- **กันการยัดข้อมูล** (17 พ.ย. 2026) ผลที่ส่งเข้าหอต้องมีบันทึกการเดินติดมา สคริปต์เล่นเกมนั้นซ้ำทั้งเกม ที่นั่ง AI และช่วงที่ AI เล่นแทนตัดสินใจด้วยสุ่มของเกมเอง คำตอบอื่นมาจากบันทึก และเอนจินเปลี่ยนคำตอบที่หน้าเกมไม่มีทางส่ง (ตัวเลือกที่ไม่มีหรือปิดอยู่ จำนวนที่ไม่ใช่จำนวนเต็มบวก การ์ดในโหมดที่ตาเดินไม่ได้เสนอ) ให้เป็นคำตอบที่ถูกกติกา เกมต้องจบโดยใช้ทุกคำตอบในบันทึก รัฐในผลต้องชนะในที่นั่งของคน และทุกตัวเลขในผลต้องตรงกับที่เกมให้ ทั้งคะแนน ความชอบธรรม ตราบาป เกรฟ การ์ด โครงการ ส่วนต่าง คู่แข่ง และระดับ AI ผลที่ไม่ผ่านถูกปฏิเสธทันที ผู้เล่นเห็นเหตุบนหน้าจบเกมโดยไม่มีปุ่มลองอีกครั้ง ผลนั้นจดไว้ในชีต `hof-flagged` คู่กับสิ่งที่เกมให้จริง เช่น `score ผลบอก 21 แต่เกมให้ 12` และขึ้นในกล่อง **กันการยัดข้อมูล** ของหน้าสถิติ บัญชีที่ถูกปฏิเสธเพราะผลไม่ตรงหรือบันทึกไม่ใช่ของเกมนี้ครบ 3 ครั้งใน 7 วันถูกระงับแบบเดียวกับการตรวจทุกคืน ผลจากหน้าเกมรุ่นเก่า หน้าเกมคนละเอนจิน และตอนสคริปต์ยุ่งไม่นับ เครื่องผู้พัฒนาไม่ถูกระงับ ทุกคืนสคริปต์เล่นซ้ำผลที่ขึ้นหอก่อนรุ่น 8 ซึ่งยังไม่เคยถูกเล่นซ้ำด้วย ผลที่ไม่ตรงถูกนำออกโดยไม่ระงับใคร ชื่อผู้นำ คำนำหน้า ธง และสีเป็นของผู้เล่นเอง สคริปต์ไม่เทียบกับเกม แต่หน้าเกมแสดงเป็นตัวอักษรเสมอ
- **กันโค้ดแฝงในข้อมูล** (17 พ.ย. 2026) ทุกชื่อ ข้อความ และตัวเลขที่มาจากผู้เล่นคนอื่น ทั้งจากสคริปต์ จากไฟล์ในคลัง และจากผู้เล่นออนไลน์ ขึ้นหน้าเกมเป็นตัวอักษรเสมอ รายชื่อที่สีไม่ใช่รหัส `#rrggbb` หรือตัวเลขไม่ใช่จำนวนเต็มถูกทิ้งก่อนแสดง ความคิดเห็นที่ดาวไม่ใช่ 1 ถึง 5 ก็เช่นกัน เมื่อตั้งสคริปต์แล้ว ลานความคิดเห็นแสดงเฉพาะความคิดเห็นจากสคริปต์ ไฟล์ในคลัง และของเครื่องนั้นเอง ความคิดเห็นที่ได้จากผู้เล่นออนไลน์ไม่ขึ้น เพราะไม่ได้ผ่านการตรวจของสคริปต์ ค่าที่สคริปต์เขียนลงชีตทุกค่าที่ขึ้นต้นด้วยเครื่องหมายเท่ากับ บวก ลบ หรือ @ ถูกเก็บเป็นตัวอักษร ไม่กลายเป็นสูตรในชีตของเจ้าของ คำขอที่ยาวเกิน 300,000 ตัวอักษรไม่ถูกอ่าน และโทเค็นที่ไม่ใช่การลงชื่อเข้าใช้ Google ของแอปนี้ถูกตัดทิ้งก่อนถาม Google
- **รีเซ็ตหอเกียรติยศ** (15 พ.ย. 2026) ปุ่มสีแดงในแถบหลังบ้านของหน้าหอเกียรติยศ ต้องพิมพ์คำว่า `รีเซ็ต` ก่อนปุ่มยืนยันจะกดได้ สคริปต์ย้ายทุกแถวในชีต `hof` ไปต่อท้ายชีต `hof-archive` โดยคอลัมน์แรกเป็นเดือนของแถวกับวันที่รีเซ็ต เช่น `2026-11 รีเซ็ต 2026-11-15` ไม่มีแถวใดถูกลบ แล้วเก็บเวลาที่รีเซ็ตไว้ใน Script Properties ชื่อ `HOF_RESET` ทุกหน้าเกมอ่านเวลานี้ตอนเปิดหอเกียรติยศ แล้วซ่อนบันทึกที่เกิดก่อนหน้านั้นจากทุกแหล่ง ทั้งในเครื่องผู้เล่น จากผู้เล่นที่ออนไลน์ และจาก `data/hall-of-fame.json` บันทึกที่มีเวลากำกับเทียบถึงนาที บันทึกที่ไม่มีเวลา (ไฟล์ในคลังและบันทึกก่อนรุ่นนี้) เทียบตามวัน จึงถูกซ่อนไปด้วยถ้าชนะวันเดียวกับการรีเซ็ต หัวหอเกียรติยศบอกเวลาที่เดือนนี้เริ่มนับใหม่ ชัยชนะหลังรีเซ็ตขึ้นหอตามปกติ ส่วนบันทึกที่เคยขึ้นหอแล้วส่งซ้ำกลับเข้ามาไม่ได้ ถ้าหน้าเกมยังไม่ได้ต่อสคริปต์ การรีเซ็ตมีผลเฉพาะเครื่องผู้พัฒนา การรีเซ็ตย้อนจากหน้าเกมไม่ได้ ถ้าต้องย้อน ให้ลบ `HOF_RESET` ที่ Project Settings > Script Properties แล้วย้ายแถวจาก `hof-archive` กลับเข้าชีต `hof` เอง (ตัดคอลัมน์แรกออก) เครื่องที่เปิดหอเกียรติยศหลังจากนั้นจะเลิกซ่อนเอง

## อัปเดตเกมรุ่นใหม่

อัปโหลดทับเฉพาะ `index.html`, `flag-icons.js`, โฟลเดอร์ `assets`, `README.md` และไฟล์ใน `scripts` หรือ `LICENSES` ที่เปลี่ยน ถ้ารอบนั้นแก้กติกา เอนจิน AI หรือข้อมูลการ์ด ให้วาง `scripts/hof-apps-script.gs` ชุดใหม่ใน Apps Script แล้วทำ New version ด้วย (หัวข้อสคริปต์รุ่น 8 ด้านบน) ถ้าใส่ Client ID หรือที่อยู่หอเกียรติยศใน `config.js` บนคลังแล้ว อย่าอัปโหลด `config.js` ว่างทับ **ห้ามอัปโหลดโฟลเดอร์ `data` ทับ** เพราะไฟล์ในคลังเก็บหอเกียรติยศและความคิดเห็นจริงไว้ ส่วนในเครื่องเป็นไฟล์ว่าง

- **ความไว้ใจ** ระบบออกแบบสำหรับเล่นกับเพื่อน ทุกเครื่องถือสถานะเกมเต็ม คนที่เปิด devtools จึงดูลำดับกองทหารของคนอื่นได้ และบันทึกหอเกียรติยศปลอมแปลงได้ ปุ่มตรวจบนเครื่องผู้พัฒนาจับได้สองแบบ คือการเล่นตาม AI ของเกม (เช่นเปิดเล่นอัตโนมัติจากคอนโซล) และคะแนนที่ถูกแก้จนไม่ตรงกับเกม เจ้าของคลังลบรายการที่ไม่ต้องการออกจาก `data/hall-of-fame.json` ได้ตลอด
- **โดเมนของตัวเอง** ถ้าไม่ได้ใช้ที่อยู่ `github.io` ให้บอกเกมว่าคลังชื่ออะไร ด้วย `<meta name="fed-repo" content="ชื่อผู้ใช้/ชื่อคลัง">` และถ้า branch หลักไม่ได้ชื่อ `main` ให้เพิ่ม `<meta name="fed-branch" content="ชื่อ branch">`
- **เกมบันทึกเองอัตโนมัติเมื่อลงชื่อเข้าใช้แล้ว** ปิดหน้าไปกลางเกมแล้วกลับมากด **เล่นต่อ** ในเมนูได้ ระบบเล่นคำตอบที่บันทึกไว้ย้อนจนถึงจุดเดิม บันทึกแยกตามบัญชี คนละบัญชีบนเบราว์เซอร์เดียวกันไม่เห็นเกมของกัน
- **ลำดับการจ่าย** ค่าที่เลือกในช่องจ่ายจากมีผลตั้งแต่การตัดสินใจครั้งถัดไปของผู้เล่น ระหว่างนั้นช่องขึ้นคำว่ารอใช้ ในเกมออนไลน์ค่านี้ไปกับคำตอบของผู้เล่น ทุกเครื่องจึงเปลี่ยนลำดับที่จังหวะเดียวกัน และเกมที่เล่นต่อจากบันทึกก็ได้ผลเดิม แบบอัตโนมัติหยิบแบบหน้าเกมรุ่นก่อน คือขายตลาดกลางกับเชื้อเพลิงหยิบจากคลังก่อน อย่างอื่นหยิบจากโครงการก่อน
- **ภาพฉากหลัง** เป็นภาพของเจ้าของเกม ถ้าภาพใดไม่ใช่ผลงานของตัวเองหรือที่จ้างวาด ตรวจสิทธิ์การเผยแพร่ก่อนอัปโหลดขึ้นคลังสาธารณะ
